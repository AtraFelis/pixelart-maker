# Spec: 생성 위치를 분리한 픽셀 변환 시제품

- 변경 ID: 001-generation-spike
- 입력: [intent.md](intent.md)
- 상태: 사용자 수락 범위 구현·기술 검증 완료, 품질 개선 필요

## 사용자 흐름

1. 소재 설명, 최종 크기, 최대 색 수, 시드와 배경 방식을 지정.
2. 선택한 생성 연결 프로필과 실제 대상의 워크플로 의존성을 확인.
3. 워크플로를 검증하고 비동기 생성 요청.
4. 연결 프로필 ID와 공급자 작업 ID를 저장하고 상태 확인 후 원본을 수집. ComfyUI에서는 prompt_id를 사용.
5. 최근접 기준선과 선택한 픽셀 처리 후보를 비교.
6. 결과 PNG, 정수 확대 미리보기, 설정·검사·품질 기록 저장.

첫 버전은 CLI나 개발용 실행 경로로 검증한다. UI를 구현했다고 간주하지 않는다.

## 수용 기준

- AC-01: 빨간 물약 하나를 생성·수집·변환·저장하는 흐름이 실제 동작.
- AC-02: 32×32·64×64 출력은 실제 지정 크기이며 저장 후 재열기에서 같은 RGBA를 유지.
- AC-03: 고정 팔레트 모드의 보이는 픽셀이 팔레트에 포함되고 기본 알파는 0 또는 255.
- AC-04: 생성 원본·워크플로 사본·시드·환경·prompt_id·변환 설정·실패 원인이 보존.
- AC-05: 모델·노드 누락, 검증 거절, 생성 오류, 대기 시간 초과를 구분. 접수 불명 작업을 자동 재제출하지 않음.
- AC-06: 최소 6개 소재에 대해 원래 크기·정수 확대본과 가독성·윤곽·명암의 평가 기록 생성.
- AC-07: 외부 도구가 없어도 기본 변환이 실행되고, 실패한 후처리만 원본에서 재시도 가능.
- AC-08: 공백·한글 경로에서 이미지와 설정의 저장·재열기가 동작.
- AC-09: 프로젝트를 다른 루트 경로로 옮겨 다시 열 수 있고 머신 설정·자격증명과 내부 상대 경로가 분리됨.
- AC-10: 생성 연결·입력 전송·결과 수집을 어댑터로 격리. 원격 실행 시 로컬 파일 경로·모델·VRAM을 대상 서버의 것으로 오인하지 않음.

## 설계 제안

Python에 작업 명세, MCP 어댑터, 기본 픽셀 처리, 검사, 실행 진입점을 분리한다. TypeScript UI와 SQLite는 이 변경에서 필요하지 않다.

설정 입력은 설명·최종 크기·팔레트·시드·워크플로 참조다. 모델 생성 크기는 최종 크기와 별도다.

작업별 디렉터리에 요청 JSON, 실행 워크플로, 원본 PNG, 변환 후보, 확대본, 결과 메타데이터를 둔다. 사용자 결과는 data 또는 output 아래에 저장하고 Git에서 제외한다.

MCP 연결 후 실제 입력 스키마를 확인한다. 로컬 MCP의 validate_workflow valid 판정, 도구 오류, JSON 텍스트 응답과 구조화 응답을 정규화한다. 다른 공급자는 별도 도구 매핑과 대상 검증을 사용한다. 제출 이후의 연결 문제는 원래 서버의 작업 상태 확인으로 해결한다.

[PC 이동과 생성 서버 선택](../../architecture/execution.md)을 적용한다. 첫 시제품에서 다른 경로로의 이동과 어댑터 경계를 검사하며, 두 번째 실제 PC·원격·클라우드 통합 검증은 환경을 연결했을 때 별도로 기록한다.

## 표현과 도구 평가

자동 검사는 규격만 판정한다. 실제 크기의 실루엣, 특징과 윤곽·명암은 사람이 확인한다. 평가가 낮아도 기록을 숨기지 않고 모델·후처리 변경의 근거로 사용한다.

Pixel Art Fixer와 Perfect Pixel은 비교 후보이며 필수 의존성으로 확정하지 않았다. 현재 설치된 모델이나 특정 축소 배율 역시 최종 선택으로 확정하지 않는다.

## 위험과 후속 결정

자동 배경 제거의 특징 손실, 격자 오탐, 32×32 축소의 세부 손실, GPU 부족을 관찰한다. 형태·배경 실패가 있으면 원본과 실패를 보존하고 수동 조정 가능 지점으로 기록한다.

보호 영역 합성·인페인트는 후속 변경에서 검증한다. 이 단계가 완성형 편집 앱은 아니다.

## 2026년 10월 31일 구현 수락과 기술 선택

사용자가 Python 명령줄 시제품의 설명을 확인한 뒤 “좋아. 진행해줘.”라고 요청했다. 생성·변환·저장·보고서와 6개 소재 평가 범위를 구현한다.

Python 3.11~3.13, uv와 잠금 파일, Pillow·NumPy·MCP Python SDK 1.x를 사용한다. 초기 연결은 로컬 MCP이며 공급자 계약과 원격 자체 운영 ComfyUI HTTP 어댑터를 분리한다. 관리형 클라우드 인증·실제 다른 PC는 미검증 범위로 남긴다. 표준 unittest를 사용하며 CLI·워크플로·요청·파일 저장·픽셀 변환·오류 복구를 검증한다. 전체 UI·모델 다운로드·노드 설치·배포는 수행하지 않는다.

## 구현에서 구체화한 범위

생성은 코어 노드의 텍스트 입력을 지원한다. 로컬 MCP와 자체 운영 ComfyUI HTTP 어댑터를 분리한다. 입력 이미지 업로드·인페인트·취소는 후속 기능이다. 변환 비교는 최근접·팔레트별 셀 다수결·보수적인 주기적 경계 격자 후보다. 외부 격자 도구 두 종류는 설치하지 않았다. 격자 후보는 합성 확대 입력에서 검증하고 실제 생성물에서는 검출 여부와 한계를 기록한다.

## CodeRabbit 검토 후 보완 기준

- 고정 팔레트는 정확한 #RRGGBB 문자열만 허용한다.
- 빈 전경에서 grid를 요청하면 설명 가능한 ValueError로 종료한다.
- 토큰을 사용하는 HTTP는 루프백에만 허용하며 API 리다이렉트는 따라가지 않는다.
- 전송 전 인증 누락과 명시적 4xx 접수 거절은 접수 불명과 구별한다. 네트워크 단절·5xx·응답 해석 실패에는 자동 재제출을 금지한다.
- 샘플 재사용은 저장된 요청과 현재 정의가 같을 때만 허용한다. 불일치하면 새 출력 폴더를 요구한다.
