## 실행 환경

Python 3.12.14, Pillow 12.3.0, NumPy 2.5.4, MCP Python SDK 1.30.0. 전체 의존성은 uv.lock에 있다.

서버는 로컬 ComfyUI v0.43.2, comfy-cli 1.22.0, RTX 5070 약 12GB였다. 실제 조회 당시 약 10.8GiB VRAM이 사용 가능했다. 기존 체크포인트 하나를 사용했고 기존 ComfyUI·모델·노드 설치는 바꾸지 않았다.

## 실제 실행 명령과 결과

저장소 루트, Windows PowerShell에서 실행했다.

- uv sync --locked: 잠금 파일 확인 및 프로젝트 전용 환경 설치 성공.
- uv run --locked python -m unittest discover -s tests -v: 25개 통과, 최종 실행 약 0.98초, 종료 코드 0.
- uv run --locked python -m compileall -q src tests examples: 종료 코드 0.
- uv build --wheel: dist/pixelart_maker-0.1.0-py3-none-any.whl 생성, 종료 코드 0.
- uv run --locked pixelart --help: 다섯 명령 표시, 종료 코드 0.
- uv run --locked pixelart doctor: 실제 서버와 체크포인트 확인, 종료 코드 0.
- uv run --locked pixelart inspect output/evaluation/potion: 저장된 상대 경로 자산·작업·설정 조회 성공.

최초 생성은 프로그램의 generate --submit-only로 제출하고 resume으로 실제 수집했다. 물약 첫 작업 ID는 9aac339c-d518-489e-ada4-3dc0aa403142, 개선 작업은 c327c0f4-885f-4114-bbba-2d5321d24eed였다.

examples/run_samples.py를 실행해 여섯 실제 MCP 작업을 순차 생성·수집했다. 마지막 처리 코드로 원본만 다시 처리해 비교 보고서를 갱신했다. 결과는 output/evaluation 아래에 있으며 Git에서 제외된다.

## 수용 기준별 근거

- AC-01: 물약의 실제 제출·수집·변환·PNG 저장·재열기 완료.
- AC-02·03: 32·64 해상도, 색 수, 고정 팔레트, 이진 알파, PNG 왕복 자동 검사. 실제 여섯 소재의 두 기본 후보도 규격 통과.
- AC-04: 각 프로젝트의 상대 경로 자산, request·workflow·seed·job_id·환경·처리 설정 보존. 진단의 오류 종류·발생 단계 저장.
- AC-05: 도구 오류·접수 불명·대기·서버 변경에 대한 자동 검사. 접수 불명은 자동 재제출하지 않음.
- AC-06: 여섯 소재의 원래 크기·확대본과 첫 실패 원본을 시각 점검. [상세 평가](evaluation.md)에 내용 실패와 한계를 기록.
- AC-07: 외부 격자 도구 없이 변환 동작. 확정 작업은 재제출 없이 수집·처리 재개.
- AC-08·09: 한글·공백 경로와 다른 루트로 프로젝트 복사 후 서버 없이 재열기 자동 검사.
- AC-10: 공급자 분리, 원격 자체 운영 API의 대상 조회·제출·기록·안전한 파일명 수집을 로컬 모의 HTTP 서버로 검사.

## 검사 중 확인·개선

첫 물약은 배경과 화면 장식이 섞여 표현 실패였다. 프롬프트와 생성 조건을 바꾸고 원본을 보존한 채 비교했다. 픽셀 규격 통과를 미적 성공으로 취급하지 않았다.

주기 격자는 합성 확대 입력에서만 정확한 복원을 확인했다. 실제 여섯 생성물은 탐지 조건을 만족하지 않아 격자 후보를 생략했다.

## 계획과 실제 변경

실행 흐름·워크플로·격자 후보 모듈, 프로필 예제와 여섯 샘플 실행 예제를 추가했다. 외부 Pixel Art Fixer·Perfect Pixel의 설치·품질 비교는 하지 않았다. 자체 격자 후보와 기준선 비교의 한계를 명세와 평가에 기록했다.

첫 실험 결과에 따라 기본 생성 조건을 1024×1024, 28 steps, CFG 7로 조정했다. 초기 UI·인페인트·취소·DB는 구현하지 않았다.

## 미검증 범위와 완료 판단

- 실제 두 번째 PC, 원격 GPU, 관리형 Comfy Cloud 인증·전송·생성은 미검증.
- 실제 다른 OS의 설치는 미검증.
- 단일 체크포인트·소수 소재 결과이며 사용자 취향 평가·객관적인 범용 품질·GPU 생성 속도 비교는 미완료.
- 동전·검은 요청 내용 실패, 상자는 열린 형태로 불일치. 모든 결과는 사용자 시각 검토 대상으로 유지.
- 작성 에이전트 자체 점검이며 독립 리뷰는 없음.
- 커밋·push·외부 배포는 수행하지 않음.

이 변경의 완료는 반복 실행 가능한 첫 CLI 시제품과 기술 검증·품질 조사까지다. 전체 제작 앱이나 모든 소재의 품질 보장은 아니다.
