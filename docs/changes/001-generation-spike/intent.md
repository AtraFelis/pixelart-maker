## 문제

픽셀풍 이미지 생성과 작은 크기에서 읽히는 픽셀아트 완성 사이에 격자·색상·배경·표현 손실 문제가 있다. 현재 PC와 도구 조합이 이 과정을 해결하는지는 아직 실험하지 않았다.

## 원하는 결과

ComfyUI MCP로 생성한 원본을 보존하면서 32×32·64×64 픽셀 결과와 비교 미리보기, 규격 검사 결과를 저장한다. 먼저 빨간 물약 한 개로 전체 경로를 연결하고 최소 6개 대표 소재로 적용 범위와 실패 원인을 확인한다.

## 대상과 범위

다른 PC로 이동할 수 있는 개인용 시제품이다. 기본 텍스트 생성 워크플로, 파일 수집, 기본 픽셀 처리, 평가 기록이 대상이다. 첫 실제 생성은 현재 접근 가능한 서버에서 확인하되, 생성 연결과 머신 설정을 분리한다. 다른 프로그램·MCP는 품질 개선에 적합한 경우 조합한다.

전체 편집 UI, 부분 재생성, 프로젝트 DB, 애니메이션·타일셋, 모델 학습, 원격 서비스 배포는 제외한다.

## 제약

- 기본 생성 경로는 ComfyUI MCP이며 로컬·원격 어댑터를 교체할 수 있게 설계.
- 기본 동시 생성 1개. 실제 실행 대상의 연결·기능·모델을 확인하며 로컬 VRAM 조회로 원격 실행을 제한하지 않음.
- 생성 원본은 덮어쓰지 않음.
- 팔레트와 투명도 규격 통과를 그림 품질 통과로 오인하지 않음.
- 추가 모델·노드·유료 서비스는 도입 이유와 작업 범위를 먼저 명시.
- 전체 앱의 기술 스택을 이 시제품에서 불필요하게 확정하지 않음.

- 자동 격자 복원과 목표 크기 재구성 중 어떤 입력에 무엇이 유리한가: 결과별 기록.
- 구체적인 Python·패키지 관리자·이미지 라이브러리 버전: 구현 시작 시 호환성을 확인해 고정.
- 사용자 취향에 맞는 픽셀 표현 기준: 결과 비교에서 반영.

## 2026년 10월 31일 구현 수락과 기술 선택
