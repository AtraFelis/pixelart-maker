# Intent: 다른 PC와 원격 생성 지원

- 변경 ID: 002-portable-execution
- 날짜: 2026년 10월 31일
- 상태: 요구 확인, 설계 문서 반영

## 문제와 원하는 결과

현재 계획은 이 PC의 로컬 ComfyUI를 기본 가정으로 삼아 다른 PC로 프로젝트를 옮기거나 클라우드에서 생성할 요구가 충분히 드러나지 않는다.

사용자는 다른 로컬 PC로 이동하고, 생성은 로컬·다른 머신·클라우드에서 선택할 수 있기를 원한다. 편집·프로젝트 저장과 생성 서버의 위치를 분리한다.

## 범위

현재 제품 정의·전체 계획·첫 시제품 초안과 검증 기준을 갱신한다. 앱·클라우드 연결 구현, 서비스 선택·가입, 배포와 비용 지출은 수행하지 않는다.

## 수락 근거

사용자, 2026년 10월 31일: “다른 PC에서도 사용할 수 있게끔”, “다른 로컬 PC로 옮기거나, comfy UI를 로컬이 아니라 클라우드에서”.

요구와 그 설계 반영 범위의 근거다. 특정 공급자나 OS 전체 지원, 자동 동기화에 대한 결정은 아니다.
