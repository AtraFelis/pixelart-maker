# Plan: 이식성과 원격 생성 요구 반영

- 입력: [spec.md](spec.md)
- 상태: 문서 반영

## 파일과 순서

1. docs/architecture/execution.md: 프로젝트 이동·연결 어댑터·원격 자산·작업 추적 설계.
2. README.md, docs/project.md: 다른 PC와 원격 생성 요구 및 설계 진입점 추가.
3. 전체 개발 계획: 로컬 전용·원격 후순위 가정 수정.
4. 001의 intent·spec·plan·evidence: 첫 시제품의 공급자·경로 분리와 후속 검증 명시.
5. docs/verification.md: 프로젝트 이동·원격 생성 검사 추가.
6. 현재 변경의 evidence: 실제 수행한 문서 검증과 미검증 범위 기록.

## 위험과 검증

기존 조사 대화와 000의 역사적 기록은 보존한다. 전체 개발 계획은 현재 요구를 담는 문서이므로 이번에 갱신한다.

문서 링크·공백 검사와 변경 문구 검사를 수행한다. 가상 경로·모의 서버 검사를 실제 다른 PC·클라우드 실행 증거로 취급하지 않는다.

## 수락 근거와 되돌리기

사용자가 명시한 PC 이동·클라우드 생성 요구를 설계에 반영한다. 문서 변경만 있으며 계정·앱·데이터 마이그레이션이나 외부 배포는 없다.
