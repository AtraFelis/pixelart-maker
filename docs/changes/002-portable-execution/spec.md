# Spec: 프로젝트 이동과 생성 위치 분리

- 입력: [intent.md](intent.md)
- 상태: 사용자 요구를 반영한 설계, 앱 미구현

## 수용 기준

- AC-01: 동일 PC, 다른 로컬 PC, 원격 자체 운영 ComfyUI, 관리형 클라우드를 구분해 설계한다.
- AC-02: 프로젝트 자산·머신 설정·생성 프로필을 분리하고 상대 경로·자격증명 제외를 명시한다.
- AC-03: 입력 업로드·결과 수집·공급자별 작업 ID·실행 대상 의존성 검사를 설계한다.
- AC-04: 첫 시제품이 로컬에 결합되지 않도록 파일·수용 기준을 갱신한다.
- AC-05: 기존 전체 계획과 README·project가 새 요구와 모순되지 않는다.
- AC-06: 실제 원격·다른 PC·클라우드 실행은 검증 전 지원 완료라고 표시하지 않는다.

구체적인 설계는 [실행 구조](../../architecture/execution.md)에 기록한다.

## 결정과 남은 질문

다른 PC로의 이동과 로컬·원격 선택은 제품 요구다. 첫 확인 OS는 Windows로 두되 다른 OS 지원은 아직 확정하지 않는다.

실제 클라우드 공급자·접속 주소·인증은 연결 구현 단계에서 선택한다. 지금은 특정 서비스에 가입하거나 계정·키를 요청할 필요가 없다.
