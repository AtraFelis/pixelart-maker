# Intent: 프롬프트 기본값의 아이템 편향을 후속 작업으로 기록

- 변경 ID: 006-prompt-profiles.
- 날짜: 2026년 10월 31일.
- 상태: 문서 기록. 앱 수정은 미착수.

## 확인한 문제

현재 공통 워크플로의 네거티브에는 human·person·body·face와 배경 소재 억제 단어가 있고, 포지티브에는 single isolated object가 자동 추가된다. 초기 여섯 아이템 비교용 조건이 모든 생성에 고정돼 단일 캐릭터 요청과 충돌한다. 사용자의 실제 시도는 “금발 여성 기사가 검 끝이 하늘로 향하게 든 채 경례하는 모습”이었다.

## 기존 기록의 누락

기존 계획에는 캐릭터·방향·스타일 일관성 확장만 있었으며, 이 기본값 충돌과 네거티브 편집·프리셋 분리는 명시된 후속 작업이 아니었다. 단일 캐릭터 생성의 기본값 문제를 장기적인 동일 캐릭터 일관성 기능으로 미루지 않는다.

## 이번 변경의 범위와 근거

사용자가 “그건 나중에 처리하게끔 문서 같은 데에 작성되어 있는 거야?”라고 물어 실제 기록을 확인했다. 이번 변경은 알려진 문제·우선순위·후속 수용 기준을 문서에 남긴다. 기능 구현이나 구현 완료를 주장하지 않는다. 다음 생성 기능 변경에서 우선 해결할 문제로 추적한다.

생성 코드·모델·노드·기존 자산·저장 형식은 이 문서 변경에서 수정하지 않는다. 후속 앱 수정은 별도 구현 변경으로 수행하며 그때 실제 검증 증거를 기록한다.
