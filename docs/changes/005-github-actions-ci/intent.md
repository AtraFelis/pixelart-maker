# Intent: PR마다 운영체제별 CI 실행

- 변경 ID: 005-github-actions-ci.
- 날짜: 2026년 10월 31일.
- 상태: 구현·로컬 검사·최초 CI 여섯 조합 성공. CodeRabbit 추가 지적의 실행 증거 보완. 최신 CI·스레드는 PR 참조.

CodeRabbit의 코드 검토와 별도로 실제 설치·테스트·빌드가 통과하는지 PR마다 자동 확인한다. 기존 44개 테스트는 로컬 결과였고 GitHub Actions는 아직 없었다.

사용자는 잠금 설치, 테스트·문법·wheel·CLI, Windows·Linux 검사를 제시한 뒤 “진행해줘”라고 요청했다. 이 범위의 워크플로 구현·실행·별도 PR 제출을 수락한 근거다. 기존 요청에 따라 PR 전 CodeRabbit 검토와 타당한 수정 반영도 수행한다.

기본 CI에는 ComfyUI·GPU·모델·생성 API 인증을 요구하지 않는다. 그림 품질 평가는 기존의 별도 실제 생성 평가로 유지한다. 브랜치 보호·자동 병합·배포·PyPI 게시·유료 러너는 이번 범위가 아니다.
