# Spec: 삭제된 참고 파일 의존성 제거

- 입력: [intent.md](intent.md)
- 상태: 요청 범위 반영

## 수용 기준

- AC-01: README에서 삭제된 파일 링크가 제거된다.
- AC-02: 전체 개발 계획의 기반 자료 설명이 남아 있는 조사 결과·출처를 기준으로 정리된다.
- AC-03: 현재 검증 계약은 삭제 파일의 존재·해시·검사 제외를 요구하지 않는다.
- AC-04: 되돌리기 안내가 사용자의 삭제 결정을 뒤집지 않는다.
- AC-05: 000·002의 증거는 당시 기록임을 명시하며 검사 수치·해시 등 과거 사실을 바꾸지 않는다.
- AC-06: 모든 현재 Markdown 링크와 공백 검사가 통과한다.

앱의 요구사항·픽셀아트 품질 기준·로컬 및 원격 실행 구조는 유지한다.
