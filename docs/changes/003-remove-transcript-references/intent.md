# Intent: 삭제된 대화 기록 참조 정리

- 변경 ID: 003-remove-transcript-references
- 날짜: 2026년 10월 31일
- 상태: 사용자 요청 범위 수락

## 문제와 원하는 결과

사용자가 저장된 조사 대화 기록을 삭제했다. README 링크와 보존·검증 지침이 삭제 전 상태여서 문서를 따라가기 어렵다.

현재 사용하는 문서와 검증 절차에서 삭제 파일 의존성을 제거하고, 과거 검사 기록은 당시 증거로 보존한다.

## 범위와 수락 근거

사용자 요청: “삭제했고, 관련해서 링크랑 정리해줘.”

문서 정리만 수행한다. 삭제된 파일 복원, 다른 파일 삭제, 앱 변경, 커밋·push는 포함하지 않는다.
