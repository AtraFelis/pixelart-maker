## 범위·위험·되돌리기

삭제 파일을 복원하거나 원본 대화·코드·데이터를 변경하지 않는다. 과거 해시·검사 수치는 현재 필수 조건이 아닌 역사적 사실로 유지한다.

문서 변경이므로 앱 실행 검사는 해당하지 않는다. 되돌리더라도 사용자가 삭제한 파일을 자동 복원하지 않는다.
