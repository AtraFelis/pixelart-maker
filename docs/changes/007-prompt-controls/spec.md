# Spec: 프리셋과 실제 프롬프트

- 새 요청의 기본값은 common v1. 소재·인물·배경을 억제하거나 단일 오브젝트를 강제하지 않는다.
- item v1은 이전 양·음성 텍스트를 정확히 보존한다. character v1은 인물과 자세의 가독성을 유도하되 성별·자세를 강제하지 않는다.
- generate의 --prompt-preset, --positive-prompt, --negative-prompt를 제공한다. description을 프리셋으로 구성한 뒤 양·음성 각각의 사용자 대체 문자열을 적용한다. 음성 빈 문자열은 허용하고 양성 빈 문자열은 거절한다. 알 수 없는 프리셋·버전·타입은 제출 전에 거절한다.
- prompts 명령은 서버 없이 실효 텍스트를 미리 보여준다. prompts --project는 저장한 실제 텍스트를 보여주고 편집 옵션 혼합은 거절한다. inspect에도 사용 가능한 실효 텍스트를 포함한다.
- 새 생성은 request.json, prompts.json, project.json, workflow.json에 프리셋·버전·입력·실효 텍스트를 일관되게 저장한다. 기존 프로젝트는 저장된 워크플로에서 실제 텍스트를 조회한다. 재개는 그래프를 바꾸거나 재제출하지 않는다.
- 새 필드가 모두 없는 예전 Request는 item v1으로 정규화한다. 모델 비교 정의 v1도 item v1으로 해석하고 v2는 명시적 공통 설정과 샘플별 실효 텍스트를 고정한다. 프롬프트 옵션은 공유 설정에만 허용하고 변형별·샘플별 덮어쓰기는 거절한다. 정의가 다른 비교 폴더는 재사용하지 않는다. 동등한 v1 아이템 비교는 원본·작업 ID·시간을 보존해 재사용한다.
- 자동 규격 검사와 표현 평가는 구별한다. 기존 6개 아이템은 동일 item v1 그래프와 저장 출력으로 회귀 확인하고 여성 기사는 common·character의 실제 새 생성에서 금발·갑옷·칼끝 방향·경례를 따로 평가한다.
