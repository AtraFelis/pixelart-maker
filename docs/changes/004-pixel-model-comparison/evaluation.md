# 실제 세 구성·여섯 소재 비교

2026년 10월 31일 작성 에이전트가 원본·32/64 최종·정수 확대본을 직접 확인했다. 이는 사용자 품질 수락이나 독립 아트 평가가 아니다. 원본과 비교 시트는 로컬 output/model-comparison에 보존하며 Git에는 넣지 않았다.

## 조건과 기술 검사

examples/samples.json의 물약·사과·동전·칼·상자·열쇠, seed 31415~31420을 사용했다. 세 구성 모두 1024×1024, 28 steps, CFG 7, euler_ancestral, normal, denoise 1, batch 1이다. 최종은 물약·사과·동전·열쇠 32×32, 칼·상자 64×64, 최대 16색, corner 배경 제거 tolerance 36, padding 2, majority 후보를 사용했다. LoRA 강도는 모델·CLIP 모두 1이다.

- Illustrious 기존 구성: 규격 6/6 통과, 주기적 격자 감지 0/6.
- SDXL base + FP16 보정 VAE: 규격 6/6 통과, 격자 감지 0/6.
- 같은 SDXL/VAE + Pixel Art XL: 규격 6/6 통과, 격자 감지 6/6.

원본 색 수·감지·시간은 [results.json](results.json)에 있다. 격자 감지는 보수적인 실험 알고리즘의 결과이며 올바른 원래 격자나 예술적 완성도를 증명하지 않는다. 시간은 제출·대기·수집·CPU 후처리를 포함한 클라이언트 경과 시간이며 GPU 추론 시간으로 해석하지 않는다.

## 소재별 관찰

- 물약: 기존 구성은 작은 빨간 둥근 병으로 읽힌다. SDXL base는 긴 목과 빈 흰 부분이 커 요청한 낮고 둥근 형태와 다르다. LoRA는 병 형태가 선명하지만 넓은 흰 라벨이 생겨 빨간 액체·흰 하이라이트라는 요구와 차이가 있다.
- 사과: 기존 구성은 과실 형태가 읽히지만 색·윤곽이 단순하다. SDXL base는 여러 잎과 큰 흰 내부가 생긴다. LoRA는 잎 하나와 빨간 사과 형태가 좋아졌지만 배경의 그림자가 최종에도 붙고 잎·질감이 축소 중 뭉친다.
- 동전: 기존 구성은 둥근 동전 대신 별 자체다. SDXL base는 여러 동전과 별 무리여서 단일 오브젝트 요구에 실패한다. LoRA는 원형 테두리 안에 별이 있는 단일 동전으로 가장 명확하게 개선됐다.
- 칼: 기존 구성은 인물 실루엣 두 개를 함께 생성한다. SDXL base와 LoRA는 칼 한 자루로 개선됐다. 다만 둘 다 칼날이 아래를 향하므로 위를 향하라는 방향 요구는 실패한다. LoRA만으로 해결됐다고 볼 수 없다.
- 상자: 기존 구성은 열린 상자다. SDXL base는 닫힌 상자와 사선 구도라는 요구에 더 가깝다. LoRA도 닫힌 상자와 금속 띠가 명확하나 정면에 가까워진다. 금속 테두리·잠금 장치의 세부가 64픽셀에서 일부 혼잡하다.
- 열쇠: 기존 구성은 대각선 방향이지만 작은 크기의 윤곽이 거칠다. SDXL base와 LoRA는 열쇠 형태가 읽히지만 수직으로 서 있어 대각선 요구와 다르다. 복잡한 고리와 이빨의 세부는 32픽셀에서 일부 손실된다.

## 판단과 후속 범위

이번 여섯 고정 시드에서는 LoRA가 픽셀 질감과 일부 단일 아이템 표현에 유리했다. 모든 의미·방향·배경 요구를 지키지는 못했다. Illustrious와의 차이는 base·VAE가 함께 바뀐 구성 비교다. LoRA 효과를 따로 판단하는 비교 대상은 동일 SDXL base/VAE 두 구성이다.

기본 모델을 자동 변경하지 않았다. 다음 품질 작업은 사과의 붙은 그림자 제거, 물약의 라벨·액체 구분, 칼·열쇠 방향 제어와 작은 크기에서의 윤곽 정리다. 시드·프롬프트 반복, 다수 사용자 평가와 실제 클라우드·두 번째 PC는 미검증이다.
