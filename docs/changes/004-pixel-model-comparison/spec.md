# Spec: 선택적 LoRA·VAE와 제어된 비교

- 입력: [intent.md](intent.md)
- 상태: 구현·기술 검사 완료, 표현 평가 기록

## 수용 기준

- AC-01: --lora·--lora-strength·--vae를 요청·CLI·저장된 설정에서 지원하며 기존 무-LoRA 호출을 유지한다.
- AC-02: LoraLoader의 모델과 CLIP 출력을 샘플러와 두 텍스트 인코더에 연결한다. VAE 선택 시 VAELoader를 디코더에 연결한다.
- AC-03: 실제 대상에서 파일·노드의 존재를 확인하고 누락 시 제출하지 않는다. 로컬·원격 프로바이더에 같은 요청을 반영한다.
- AC-04: 선택한 가중치의 출처·revision·SHA-256·파일명·라이선스를 기록하고 Git에서는 제외한다.
- AC-05: 기존 모델, SDXL base + 동일 VAE, 같은 base/VAE + LoRA의 세 구성에 여섯 동일 요청·시드·샘플링·후처리를 적용한다.
- AC-06: 중단된 비교는 기존 프로젝트를 확인해 재개하고 다른 설정의 기존 경로를 재사용하지 않는다.
- AC-07: 원본과 원래 크기·확대본을 보고 내용 일치와 픽셀 표현을 별도로 평가한다. LoRA만의 효과는 SDXL 두 구성에서 비교한다.
- AC-08: 자동 검사·문법·wheel·문서 검사를 실제 실행하고 작업 단위 PR로 제출한다.

## 모델 선택

Pixel Art XL은 제작자가 SDXL base와 함께 사용하는 LoRA다. 현재 Illustrious에 곧바로 조합하지 않고 기반 모델을 별도 사용한다.

SDXL 두 구성은 같은 FP16 보정 VAE를 사용한다. 일반 모델과의 비교는 기반 모델·VAE가 함께 달라진 구성 비교이며 단독 LoRA 인과 효과로 해석하지 않는다.

레퍼런스 이미지와 별도 LCM LoRA는 이번 비교에 추가하지 않는다. 제작자의 8배 축소 안내는 참고하고 최종 32·64 규격과 구분한다.
