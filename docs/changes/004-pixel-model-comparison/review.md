## 4431659833 — 비교 조건의 임의 덮어쓰기

수용. 변형의 steps·cfg·seed·size·prompt, 샘플의 모델 선택·steps가 Request로 그대로 유입됐다. 공통 settings도 출처가 다른 필드를 허용했다. 변형은 모델 선택, 샘플은 소재·프롬프트·크기·시드, settings는 공통 생성·후처리 조건만 허용하고 알 수 없는 필드를 거절한다. make_request에서도 검증해 직접 호출이 허용 경계를 우회하지 않도록 했다. 정상 LoRA·VAE·강도·공통 조건은 유지한다.

## 4431659836 — 기존 작업 재개에서 새 생성용 사전 점검

수용. 미완료 프로젝트가 있으면 변형 전체의 모델·노드를 다시 확인해, 이미 접수된 작업의 결과 수집과 저장 원본의 로컬 후처리까지 막혔다. 기존 프로젝트는 pipeline.resume으로 전달한다. 새로운 프로젝트 제출에 도달했을 때만 AsyncExitStack으로 공급자를 열고 사전 점검하며 같은 변형의 새 제출에서는 재사용한다. 작업 재개·수집에서 자동 재제출은 하지 않는다.

## 실패 재현과 수정 검증

- 수정 전 python -m unittest discover -s tests -p test_comparison_review.py -q: 8개 검사 중 실패 16건·오류 1건. 허용되지 않은 필드가 통과했고, 모델 제거 시 수집이 막혔고, 저장 원본의 오프라인 재처리도 서버에 연결했으며, 뒤에 있는 새 작업의 사전 점검이 먼저 실행돼 앞선 저장 원본도 처리하지 못했다.
