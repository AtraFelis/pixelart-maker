# Intent: 큰 픽셀 캔버스와 정수 배율 출력

## 문제와 원하는 결과
32·64 고정 출력 때문에 캐릭터 세부와 큰 배경을 시험하기 어렵다. 픽셀 작업 크기와 화면에 표시할 확대 출력의 크기를 분리한다. 128·256 이상 정사각형과 480×270·1920×1080 같은 직사각형 캔버스, 480×270 → 1920×1080 정수 확대를 CLI에서 선택한다.

## 수락 근거
사용자가 큰 해상도 픽셀아트의 가능성과 두 크기 구분 설명 후 2026-11-02 “좋아. 그러면 다음 단계 진행해줘.”라고 수락했다. 이 수락은 해상도 설정·저장·검증·호환성과 관련 성능/미리보기 보완, 기존 모델의 실제 연결·표현 확인, 리뷰·작업 단위 PR까지 적용한다. 이미 승인한 작업의 재승인은 요청하지 않는다.

## 범위
큰 이미지 기반을 먼저 구현한다. 타일/구역별 AI 생성·편집 UI·새 모델/노드 설치·배경 제거 알고리즘 개선·유료 서비스·자동 병합은 제외한다. 큰 캔버스나 확대 출력이 생성 원본의 세부 정보를 늘리거나 동일한 스타일·정확한 자세를 보장하지 않는다.
