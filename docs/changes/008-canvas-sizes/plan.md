## 위험과 되돌리기
픽셀 수·확대 배율은 메모리/디스크/CPU 비용을 늘리므로 상한과 제한 미리보기를 제출 전 적용한다. 생성 영역은 기존 1024² 픽셀 예산 안에서만 확장한다. 다운샘플링·알파·팔레트·비율을 회귀 검사한다. 큰 캔버스는 큰 생성 모델·타일 생성이나 미적 완성을 의미하지 않는다. 코드 revert로 되돌릴 수 있으나 새 크기의 프로젝트는 지원 버전 이상으로 연다. 원본·기존 저장 프로젝트를 삭제하지 않는다.
